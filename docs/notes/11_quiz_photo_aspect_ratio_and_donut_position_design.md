# 11. クイズ写真アスペクト比固定とカラーピッカー配置設計

## 1. 背景と目的 (Background & Objectives)

### 1.1 背景と課題
- **写真アスペクト比の不定性**: 現在のクイズ出題画面（`LayoutOverlay`）では、カードの高さや幅が画面サイズやコンテナ設定に依存しており、公式生写真（L判縦長）の本来の比率（ヨリ・チュウ・ヒキ等）がトリミングや縦横比の歪みで崩れる場合がある。
- **カラーピッカー（ドーナツ）の顔被り**: 現行のカラー選択モーダル（`DonutRingModal`）は画面中央を基準として配置（`translateY` によるオフセット）されているため、画面サイズによってメンバーの顔（目・鼻・口）にドーナツ円環が重なってしまい、推しの表情を見ながら解答するユーザー体験を損ねている。

### 1.2 目的
1. **生写真体験の再現**: 公式生写真の標準規格に合わせた縦長アスペクト比を適用し、カードの視覚的統一感とコレクション感を高める。
2. **顔被りゼロのカラーピッカーUI**: ドーナツ円環をメンバーの顔から退避させ、写真下部に位置するペンライトの直上に配置することで、視認性と操作性を両立する。
3. **柔軟な変更容易性の確保**: アスペクト比固定は見直し・解除の可能性があるため、いつでも即座に元に戻せる疎結合な設計とする。

---

## 2. 設計決定事項 (Design Decisions)

### 2.1 写真アスペクト比（生写真 L判 縦長）の固定
- **標準アスペクト比**: 公式生写真規格である **L判縦長（89 mm × 127 mm）** を採用。
  - CSS定義: `aspectRatio: '89 / 127'`（幅 1 に対し、高さ 約 1.427 の縦長長方形）
  - 表示設定: `object-fit: cover`（または枠内に完全収容）
  - モバイル考慮: スマホ画面（縦 667px〜844px 等）において縦スクロールが発生して解答領域が押し出されないよう、`maxHeight` や `maxWidth` で画面内収容を保証する。
- **【重要注記】解除・見直し可能性の担保**:
  - 本アスペクト比固定は、今後の実機検証やユーザー体験の評価次第で **「解除（元のレスポンシブ自由伸縮に戻す）」または「比率変更」を行う可能性がある**。
  - そのため、コンポーネント内にアスペクト比をハードコードせず、設定定数（例: `PHOTO_ASPECT_RATIO`）または切り出し可能なプロパティとして局所化し、1行の修正・フラグ切り替えで容易に無効化・調整できるように実装する。

### 2.2 カラーピッカー（ドーナツ）のペンライト相対配置
- **X軸（水平配置）**: 既存仕様を維持し、**「画面全体に対する水平中央」** とする。
  - 理由: スマートフォン片手・両手操作において左右どちらの手からも届きやすく、中央の視覚的安定性を保つため。
- **Y軸（垂直配置）**: 写真中央ではなく、**「ペンライトの少し上」** を基準に配置する。
  - 理由: 写真上部〜中央に位置するメンバーの顔に一切被らず、下部のペンライト（解答対象）との視線移動距離を最短化するため。
- **配置オフセットの定数化**:
  - 「ペンライトの上端からどれくらい離すか」の距離は、実機UIでの操作感を見ながら微調整（fix）するため、定数（例: `DONUT_OFFSET_ABOVE_PENLIGHT` または CSS 変数）として定義し、実装時に即座に調整可能な構造とする。

## 3. 実装方針とコンポーネント影響 (Implementation Plan)

### 3.1 影響を受けるコンポーネント
1. `frontend/src/features/quiz/components/layouts/LayoutOverlay.tsx`
   - 写真カード（`Paper`）に `aspectRatio: '89 / 127'` を適用。
   - 解除容易な定数定義（`ENABLE_FIXED_ASPECT_RATIO = true` / `PHOTO_ASPECT_RATIO = '89 / 127'`）を設置。
2. `frontend/src/features/quiz/components/inputs/DonutRingModal.tsx`
   - モーダルの垂直配置ロジックを更新。画面中央基準のハードコード（`translateY(135px)`）を廃止し、ペンライト位置に連動した下部アンカーまたはペンライト相対位置でレンダリング。
   - `OFFSET_ABOVE_PENLIGHT` 定数による微調整ポイントの提供。

### 3.2 検証観点
- **視認性**: メンバーの顔（頭頂部〜顎元）にドーナツ円環が重ならないこと。
- **操作性**: ドーナツの各色ジェエルおよび中央の左右ペンライト表示が片手で快適にタップできること。
- **解除容易性**: `ENABLE_FIXED_ASPECT_RATIO` フラグを false に切り替えた際、既存の柔軟なカードサイズに即座にロールバックできること。
