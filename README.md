# Penlight Quiz v2

坂道シリーズ（乃木坂46・櫻坂46・日向坂46等）のペンライトカラーを暗記・復習するためのクイズWebアプリ。
端末内での即時出題・採点に対応し、通信圏外のライブ会場でも利用可能。


## 特徴

- **圏外・オフライン動作**: 初回アクセス時にデータを端末へ保持。電波の届かないライブ会場でも、通信なしで出題・採点が可能（回答ログは電波復旧時に自動同期）。
- **選べる出題モード**: 苦手なカラーの復習、期生別の絞り込み、全体ランダムなど、習熟度や目的に合わせた出題パターンの変更。
- **ペンライト代用表示**: 各メンバーのサイリウムカラーを全画面で点灯・表示。

## 開発の背景と達成目標

旧版（v1）の実運用で生じた以下の限界を解消することを目的としています。

1. **混雑会場での完全動作**: 開演前の混雑時でもローディングが止まることなく、通信が途切れた状態でも快適に出題・採点できること。
2. **同姓同名・改名への耐性**: 名前の重複や改名、新グループの追加があっても、過去の回答履歴やメンバー写真が破損しないこと。
3. **継続的な個人運用**: 外部の有料クラウドへの依存をなくし、個人環境で維持コストをかけずに高速に動作し続けること。
