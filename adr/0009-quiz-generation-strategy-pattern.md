# 0009. クイズ出題アルゴリズムにおける Strategy パターンの採用 (0009-quiz-generation-strategy-pattern.md)

- **ステータス**: 承認 (Accepted)
- **日付**: 2026-10-03

---

## 1. 背景と解決すべき課題 (Context & Problem)

旧システムの出題アルゴリズムは完全ランダム選定だったため、以下の問題がありました。
1. **難易度・面白さのムラ**: 「スカイブルー」の出題に対して選択肢が「赤」「黄色」など無関係な色ばかりになり、クイズとして簡単すぎた。
2. **学習・復習の不能**: ユーザーが過去に何度も間違えた苦手な組み合わせを反復練習する機能がなかった。
3. **ロジックの肥大化**: 難易度調整や新ルール（同期生限定など）を 1 つの関数に `if-else` で追加していくとコードが破綻する。

---

## 2. 決定事項と具現化仕様 (Decision & Specification)

出題エンジンに **Strategy パターン** を採用し、出題ロジックを独立したインターフェース実装として分離する。

```go
type Strategy interface {
    Name() string
    GenerateQuestion(ctx context.Context, target Member, pool []Member, colors map[ID]Color, userHistory []AnswerLog) (QuizQuestion, error)
}
```

### 提供する 4 つのストラテジー仕様

| ストラテジー | 識別子 | アルゴリズム・選定ルール |
|---|---|---|
| **類似色ひっかけ (デフォルト)** | `similar_color` | 正解色との **CIELAB 色差 ($\Delta E$)** を計算し、人間にとって紛らわしい類似色（$10 \le \Delta E \le 30$）を持つメンバーを優先選出 |
| **完全ランダム** | `random` | 初心者向けに全メンバーから均等ランダム選出 |
| **同期生限定 (高難度)** | `same_generation` | 出題対象と同一グループ・同一期生のみで 4 択を構成するコアファン向け難問 |
| **忘却曲線・苦手克服** | `spaced_repetition` | ユーザーの過去誤答ログ（`ans_`）から誤答率の高いメンバーを優先選出 |

- **動的切り替え**: API クエリ `GET /api/v1/quiz/generate?strategy=similar_color` により動的に切り替え可能。
- **クライアント共有**: 同一インターフェース・アルゴリズムを TypeScript 側にも実装し、オフライン PWA 時にも同一品質で動作。

---

## 3. 採否の根拠とトレードオフ (Rationale & Trade-offs)

### 色差判定アルゴリズムの比較検討

| 手法 | 人間の視覚との一致度 | 計算負荷 | 特徴 | 判定 |
|---|---|---|---|---|
| **完全ランダム** | 一致しない | ゼロ | 簡単すぎる色ばかり並ぶ | **初心者限定** |
| **RGB ユークリッド距離** | 低い (緑が敏感、青に鈍感) | 極小 | 人間の色の見え方と大きく乖離 | **却下** |
| **CIELAB 色差式 ($\Delta E$) [採択]** | **極めて高い (人間の視覚特性に適合)** | **小 (数式 1 つ)** | 「スカイブルー」と「パステルブルー」を正確に類似色と判定 | **採用** |

- **決定打**: RGB 空間での単純な距離計算は、人間の眼の錐体細胞の感度特性（緑への高感度、青への低感度）を反映できない。CIELAB 色空間に変換して $\Delta E$ を算出することで、「ファンの誰もが悩む絶妙な難問」を数学的に自動生成できる。

---

## 4. 得られる効果と留意点 (Consequences)

### ポジティブな影響 (Positive)
- **極上のクイズ体験**: 単なる運ゲーではなく、推し活・暗記ツールとしての実用性とゲーム性が劇的に向上。
- **プラグイン拡張性**: 新しい出題イベント（例: 「誕生日記念モード」「卒業生限定モード」）を追加する際も、新規 Strategy を追加登録するだけで既存コードを無傷で保てる。

### 留意点と対策 (Negative & Mitigation)
- **初期色の Lab 変換コスト**:
  - カラーマスタの色数は数十色程度であるため、サーバー/クライアント起動時にあらかじめ Lab 値をキャッシュ保持し、実行時の計算を $\Delta E$ のみ（1 マイクロ秒未満）に抑える。
